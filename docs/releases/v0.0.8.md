# TDM 0.0.8

This release makes TDM start with Windows in the system tray, shows live activity in the main window, and lets the browser extension hand eligible HTTP/HTTPS downloads to TDM by default.

Update checks now retry transient connection and server failures. To receive updates, enable automatic update checks in Settings and make sure GitHub is reachable.

## Downloads

- Windows: `Tawaswl_Download_Manager_0.0.8_x64-setup.exe`
- macOS: `Tawaswl_Download_Manager_0.0.8_universal.dmg`
- Linux: `Tawaswl_Download_Manager_0.0.8_amd64.deb` or `Tawaswl_Download_Manager_0.0.8_amd64.AppImage`
- Browser extension: `TDM-Extension-Chrome-Edge-1.2.6.zip` or `TDM-Extension-Firefox-1.2.6.zip`

The Windows installer is for x64. Installers and extension packages are produced by the release workflow.
