# TDM 1.0.1

هذه أول حزمة رسمية من TDM على GitHub. إصدار التطبيق هو 1.0.1، وإصدار إضافة المتصفح المرفقة مستقل وهو 1.2.7.

## التغييرات

- تحديث معرّفات التطبيق ولينكس وNative Messaging إلى مساحة أسماء `tawaswlsy-stack`.
- تحديث الاسم الظاهر إلى TDM واستبدال روابط الدعم الشخصية ببريد التواصل الخاص بالمشروع.
- تصحيح بصمات SHA-256 لنسخ FFmpeg وffprobe على ويندوز لمطابقتها مع الملفات المنشورة بعد التحقق منها.
- إصلاح إشعار الوضع المصغّر عند اكتمال تنزيل سريع بين فحصين للحالة، وإتاحة تركيز لوحة المفاتيح على مناطق التمرير في التفاصيل وتحديث الرابط.
- توجيه إغلاق نافذة ويندوز عبر مسار إيقاف التنزيلات قبل إنهاء النافذة.

## التوافق والانتقال

تغيير المعرّف ليس ترقية داخل التثبيت السابق. ثبّت التطبيق والإضافة الجديدين، وأزل تسجيل مضيف Native Messaging القديم بالطريقة المعتادة للنظام أو المتصفح. يتعامل Firefox مع معرّف الإضافة الجديد كإضافة منفصلة. يبقى معرّف إضافة Chromium كما هو، لكن الإضافة المحدّثة تتصل بمضيف Native Messaging الجديد. تبقى بيانات TDM الأساسية في مجلد البيانات القياسي `tdm`؛ وقد يبدأ مخزن بيانات WebView الذي يديره Tauri من جديد. لا توجد أسماء قديمة بديلة أو مسارات ترحيل تلقائية. التفاصيل في [ADR-0001](../adr/0001-naming.md).

## التحديث اليدوي

إذا لم تتضمن صفحة الإصدار ملف `latest.json`، فالتحديث التلقائي غير متاح لهذا الإصدار. نزّل مثبّت نظامك من [صفحة الإصدارات الرسمية](https://github.com/tawaswlsy-stack/TDM/releases/tag/v1.0.1)، وأغلق TDM، ثم شغّل المثبّت وافتح التطبيق. لا تحذف مجلد بيانات TDM. راجع قسم [التوافق والانتقال](#التوافق-والانتقال)، لأن تغيير معرّف التطبيق يتطلب تثبيتًا جديدًا وإعادة تسجيل مضيف Native Messaging.

إضافة المتصفح إصدار مستقل عن التطبيق؛ حدّثها من متجر المتصفح الرسمي عند توفر الإصدار 1.2.7 هناك. ملفات `SHA256SUMS` المنشورة تساعد على كشف تلف التنزيل، لكنها غير موقّعة عندما لا تتوفر أسرار التوقيع، لذلك لا تثبت وحدها أصالة الملف. عند غياب `latest.json`، استخدم صفحة GitHub الرسمية للتنزيل والتثبيت اليدوي فقط؛ لا تتوقع إشعار تحديث تلقائي.

ينشئ CI المثبّتات والإضافة وملف `SHA256SUMS`. عند تهيئة أسرار التوقيع المحمية بنجاح، يضيف سير الإصدار بيانات التحديث الموقّعة و`latest.json`؛ وإلا تبقى الحزمة متاحة للتثبيت اليدوي دون تحديث تلقائي.

**English summary:** TDM 1.0.1 updates app and Native Messaging identifiers to the project namespace, corrects verified Windows FFmpeg hashes, fixes tray completion notifications and keyboard access, and includes browser extension 1.2.7. If a release has no `latest.json`, users must download and install it manually; `SHA256SUMS` is not signed without the release signing key. Keep the standard `tdm` data folder. See [ADR-0001](../adr/0001-naming.md) for migration details.
