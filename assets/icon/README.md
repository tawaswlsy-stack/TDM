# أيقونة TDM

هذا المجلد **هو المصدر الوحيد** لأيقونة البرنامج. اعتمدها المالك في M4 ([#6](https://github.com/tawaswlsy-stack/TDM/issues/6)). **لا تُعدَّل أشكالها ولا ألوانها، ولا يُعاد رسمها.** وكل المقاسات الأخرى تُولَّد من هذه الملفات.

| الملف | ما هو | أين يُستعمل |
|---|---|---|
| `tdm-icon.svg` | الأيقونة كاملة (البلاطة والطير)، بصيغة متجهة | المصدر الأصلي للأيقونة |
| `tdm-icon-1024.png` | نفس الأيقونة بمقاس 1024×1024 بخلفية شفافة | **منه تتولد أيقونات كل نظام** (الأمر أدناه) |
| `tdm-mark.svg` | الطير وحده بلون واحد (`currentColor`) | الشعار داخل الواجهة بجانب «TDM»، وأيقونة شريط النظام (وفي ماك صورة template تتلوّن مع الوضع الفاتح والداكن) |

## توليد المقاسات

من مجلد `apps/desktop`:

```bash
npx tauri icon ../../assets/icon/tdm-icon-1024.png -o src-tauri/icons
```

الأمر يكتب في `apps/desktop/src-tauri/icons`: ملف `.icns` لماك، و`.ico` لويندوز، وملفات PNG بالمقاسات التي يحتاجها Tauri ولينكس، ومقاسات متجر ويندوز. ويكتب أيضًا مجلدي `android` و`ios`، وهما يُحذفان: تطبيق الهاتف خارج النطاق (ROADMAP). **الملفات المولَّدة محفوظة في المستودع**، لأن البناء يحتاجها. وإذا تغيّرت الأيقونة يُعاد الأمر، ولا يُعدَّل أي ملف مولَّد باليد.

**الشعار داخل الواجهة** يُقرأ من `tdm-mark.svg` نفسه وقت البناء، ويأخذ لون النص المحيط به.
